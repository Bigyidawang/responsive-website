# Responsive Website

本项目为个人前端练习项目，使用 HTML5 和 CSS3 实现响应式企业官网页面。

## 技术栈

- HTML5
- CSS3
- Flex
- Media Query

## 项目亮点

- 响应式布局
- 支持 PC、平板和移动端
- 高保真页面复刻
- 使用媒体查询完成多端适配

## 项目说明

参考 GitHub 开源模板进行页面分析与实现，代码由本人独立完成，仅用于学习和作品展示。
